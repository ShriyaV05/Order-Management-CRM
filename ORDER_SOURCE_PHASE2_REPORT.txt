3. MIGRATION CODE & SPECIFICATION
--------------------------------------------------------------------------------
DDL statement to be executed against Turso in Phase 3:
```sql

```
Execution helper in database.py:
```python

```
Safety guarantees:
- O(1) instantaneous metadata-only alteration in SQLite/libSQL.
- Does NOT rewrite the table or lock concurrent readers.
- All historical records automatically evaluate to NULL without row updates.
- Fully idempotent: checks PRAGMA table_info before attempting alteration.
