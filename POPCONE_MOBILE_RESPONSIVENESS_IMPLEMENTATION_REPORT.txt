4. PAGE-BY-PAGE RESPONSIVE ENHANCEMENTS
--------------------------------------------------------------------------------

A. NAVIGATION (Mobile Bottom Bar)
   - On screens < 768px, desktop left sidebar and hamburger button are cleanly hidden.
   - A floating, frosted glass bottom navigation bar is fixed to the bottom of the viewport
     with safe-area inset padding (`env(safe-area-inset-bottom)`).
   - 5 thumb tabs: Dashboard, Orders, New Order (prominent elevated yellow badge),
     Inventory, and Analytics.
   - Smooth active state indicators with icons and legible 10.5px bold labels.

B. DASHBOARD
   - Desktop 5-column / staggered KPI layout cleanly reflows into a compact 2-column grid.
   - Key business metrics (Total Revenue, Orders, Bottles, Pending Dispatch) are immediately
     visible without excessive vertical scrolling.
   - Recent orders table is replaced by responsive glassmorphic cards showing Order ID,
     date, customer, order source badge, bottle quantities, payment status, and dispatch switch.
   - Desktop view at 1366px and 1920px retains original table and KPI layout 100%.

C. ORDERS MANAGEMENT
   - On mobile, the 1326px wide table is replaced with compact, scannable order cards.
   - Each card displays:
     * Header: Order ID with click-to-copy, creation date, and Order Source badge.
     * Body: Customer name, direct click-to-call phone link (`tel:`), total bottles & weight.
     * Footer: Payment status pill, amount in bold, and instant toggle for dispatch status.
   - Preserves search input, status filters, flavour dropdown, and date ranges.
   - Desktop table layout is completely preserved for laptop and desktop users.

D. NEW ORDER PAGE
   - Customer Information form fields collapse smoothly from 3 desktop columns to 2 columns
     on mobile, keeping Customer Name, Phone, and Notes full-width.
   - District, State, Payment, and Order Source are arranged in clean 2-column pairs.
   - Flavour cards display in an adaptive 2-column grid with compact +/- stepper buttons.
   - Sticky Bottom Summary Action Dock (`#new-order-mobile-dock`):
     * Anchored directly above the bottom navigation bar.
     * Live display: "X Bottles | ₹Y".
     * High-visibility "Create Order" button accessible at all times without scrolling.
     * Respects safe-area insets and does not obscure form fields.

E. MODALS (Order Details & Edit Order)
   - Transformed from overflowing desktop dialogs into ergonomic mobile bottom sheets.
   - Max height capped at 92vh with smooth internal scroll (`overflow-y: auto`).
   - Order Details: Full-width stacked primary action button ("Mark Dispatched") with
     Edit and Delete buttons arranged in a balanced thumb row below it.
   - Edit Order: Customer details form, flavour quantity controls, and Order Source dropdown
     reflow into a clean 1-column mobile flow with 0% clipping or horizontal cutoff.

F. INVENTORY & STOCK HISTORY
   - Warehouse stock levels reflow into a compact 2x2 grid fitting all 4 flavours on
     a single mobile screen.
   - Quick action buttons ("Adjust Stock", "Add Stock") span full-width for easy tapping.
   - Movement history table displays with smooth horizontal swipe support.

G. ANALYTICS
   - Time period filter pills span the full mobile toolbar.
   - Analytics KPIs reflow into a balanced 2-column grid with primary Revenue spanning full width.
   - Charts automatically scale to 100% container width with zero clipping.
